## Selected Projects

### ✈️ [Turbulence — LLM Reliability Evaluation](https://github.com/Diptesh2006/turbulence)

A reliability testing platform for LLM applications that simulates provider outages, latency spikes, malformed responses and routing failures.

**Stack:** Python · FastAPI · Server-Sent Events · LLM APIs

[Repository](https://github.com/Diptesh2006/turbulence) · [Demo](https://www.loom.com/share/f51b2dd5c6804e1c89afc02811516dbe)

### ⚖️ Jurident AI — Legal Research & Drafting Assistant

Worked on a production legal AI system for a platform serving 10k+ users. Built retrieval and backend workflows involving query rewriting, SQLite FTS5, conversational memory and citation-aware responses.

**Stack:** Python · FastAPI · SQLite FTS5 · LLMs · RAG

[Watch Demo](https://www.loom.com/share/7b92c81ec4b747a89b87f5fbada5555c)

### 📑 [DealLab — AI Deal Engineering](https://github.com/Diptesh2006/DealLab)

An AI-powered system for analyzing enterprise contract economics. Separates LLM-driven interpretation from deterministic calculations for financial analysis.

**Focus:** LLM orchestration · Structured extraction · Deterministic backend logic

[Repository](https://github.com/Diptesh2006/DealLab)

### 🛰️ Spatio-Temporal Accident Risk Prediction

Developed a geospatial ML pipeline using traffic, temporal and satellite-derived data to predict accident risk.

- Achieved **R² ≈ 0.88** in predictive modelling.
- Used Google Earth Engine for geospatial feature extraction.
- Published at **IEEE InGARSS**.

[Read Paper](https://ieeexplore.ieee.org/abstract/document/11583964)
