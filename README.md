## Things I've been building

### [Turbulence](https://github.com/Diptesh2006/turbulence)
**An LLM reliability testing platform**

What happens when an LLM provider goes down halfway through a request? Or when a response is malformed, latency spikes or fallback routing fails?

Built Turbulence to experiment with these problems through reproducible failure scenarios, provider comparisons and real-time monitoring.

`Python` `FastAPI` `SSE` `LLM APIs`

[GitHub](https://github.com/Diptesh2006/turbulence) · [Demo](https://www.loom.com/share/f51b2dd5c6804e1c89afc02811516dbe)

### [DealLab](https://github.com/Diptesh2006/DealLab)
**AI-assisted contract economics**

An experiment in separating what LLMs are good at from what they shouldn't be trusted to calculate.

The model interprets contracts while the backend handles financial calculations deterministically.

`LLMs` `Python` `Backend Engineering`

[GitHub](https://github.com/Diptesh2006/DealLab)

### Production AI & Agent Work
**Systems beyond standalone demos**

I've worked on AI applications involving retrieval, context management, tool orchestration, structured document generation and backend integrations.

Some of that work includes:
- Building retrieval pipelines with hybrid search and query rewriting.
- Designing agent workflows with planning, state tracking and failure recovery.
- Integrating LLMs into backend systems with attention to reliability and output validation.

Much of this work was developed through internships or startup collaborations, so not every codebase is public.

### Spatio-Temporal Accident Risk Prediction
**Research @ IIT Kharagpur**

Used historical accident data, satellite-derived features and geospatial modelling to study road accident risk.

The resulting model achieved an **R² of approximately 0.88** and the work was published at IEEE InGARSS.

[IEEE Paper](https://ieeexplore.ieee.org/abstract/document/11583964)
